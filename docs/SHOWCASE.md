# Showcase Captures / 分项演示

## English

The three feature clips use the real project shaders and URP camera render requests in Unity 2022.3.62f2 / Direct3D 11. The footage is generated by automated parameter sweeps, not by simulated Inspector screenshots or manual mouse interaction. No mountain assets are needed for these clips.

| Clip | Parameter | Frames | Authored playback |
| --- | --- | --- | --- |
| Coverage | CloudVolume.coverage, 0.35 to approximately 1.0 and back | 60 | 6 seconds, 10 fps |
| Sun direction | Directional Light X rotation, 15 to approximately 75 degrees and back | 60 | 6 seconds, 10 fps |
| Noise slices | Preview shader slice, 0.02 to approximately 0.98 and back, R channel | 48 | 6 seconds, 8 fps |

The 3D noise clip samples the existing ShapeWorley128 and DetailWorley64 assets with the project's noise-preview shader. It does not regenerate noise on every frame. The input/output stages of the offline Compute Shader generator are covered by the tool screenshots and release validation.

### Capture Baseline

The cloud clips start from `CloudVolume.ApplyPortfolioShotLook()` with the following temporary overrides. The included scene and saved preset bank are not rewritten.

| Setting | Value |
| --- | --- |
| Camera | Included SampleScene camera transform, animation disabled |
| Render request | 960 x 540, with a 60-pixel annotation strip added during encoding |
| Render Scale | 0.75 |
| Wind Speed | 0 |
| Temporal Accumulation | Off |
| Step Size / Max Steps | 3 / 320 |
| Light Steps | 8 |
| Density Multiplier / Threshold | 10 / 0.2 |
| Ambient Light | 0.6 |
| Sun intensity | 0.8 |
| Coverage clip Sun Light Dimmer / Silver Intensity | 1.1 / 0.5 |
| Sun clip Coverage | 0.88 |
| Sun clip Sun Light Dimmer / Silver Intensity | 1.4 / 0.65 |
| Sun clip azimuth | Camera Y rotation minus 180 degrees |

The changing value in each annotation comes from [the actual per-frame export](media/showcase-parameters.csv). Parameters follow a smooth cosine forward/back sweep. These settings are chosen to isolate controls and preserve readable highlights, not to imply that one preset is universally optimal.

### Reproduce in the Editor

1. Open SampleScene and keep the camera stationary
2. On CloudVolume, select Custom, apply Portfolio Look, then set the baseline values above; do not save into a built-in preset unless you intend to replace it
3. Set Wind Speed to 0 and disable Temporal Accumulation
4. Move the Coverage slider to compare the coverage endpoints
5. Restore Coverage to 0.88, use the sun-clip lighting values and rotate the Directional Light around X with the specified fixed Y direction
6. For noise slices, open Tools > Volumetric Clouds > Noise Preview, assign either generated Texture3D, select R and move Slice

### Diagnostic Validation

Debug screenshots use the included scene's existing cloud configuration at 1280 x 720, not the sweep overrides. Empty-space skipping OFF/ON comparison images share the same camera and Max Steps normalization. Black is no visible cloud interval; the blue-to-cyan-to-yellow-to-red ramp maps 0 to 100 percent of the configured, clamped view-step budget.

An additional zero-density regression disables opacity-based early termination: the mean budget fraction decoded from the heatmap over intersecting rays changed from approximately 0.9926 with skipping OFF to 0.4570 with skipping ON. These are quantized image-derived view-sample fractions, not timings or a general performance benchmark. Changing Aerial Perspective from 0 to 1 and enabling Temporal Accumulation changed no diagnostic pixel beyond a one-byte tolerance in that test.

The three animated clips, refreshed diagnostics and cloud-shader error checks completed successfully. Runtime frame time, fast-motion temporal behavior, XR and cross-platform behavior were not benchmarked. The full original mountain MP4 remains available alongside these feature clips.

## 中文

三段小视频均使用工程中的真实 Shader、Unity 2022.3.62f2 / D3D11 和 URP 相机渲染请求生成。它们是自动扫描参数的展示，不是模拟出来的 Inspector 或鼠标拖拽录像。每段约 6 秒，编码帧率不代表运行时性能。

覆盖率展示固定光照下的云量变化；太阳方向展示固定云形下的明暗变化；噪声切片展示已有 ShapeWorley128 与 DetailWorley64 的 R 通道，不是每帧重新运行 Compute Shader。截图中的生成器与发布验证说明单独展示离线生成部分。

云演示以 Portfolio Look 为基础，临时设置密度 10、阈值 0.2、Step Size 3、Max Steps 320、Light Steps 8、Ambient Light 0.6、太阳强度 0.8，固定相机、关闭风和时间累积。两段视频的直射光和银边系数见上表，逐帧变化数值来自 CSV。展示过程没有保存这些临时值到场景或预设。

在自己的编辑器里，可以选择 CloudVolume 的 Custom，点击 Portfolio Look 后按上表设置；拖动 Coverage 观察云量，或把覆盖率恢复到 0.88 后旋转 Directional Light 的 X。噪声预览使用 Tools > Volumetric Clouds > Noise Preview，拖入三维纹理、选择 R 并移动 Slice。需要保留原预设时，不要点击保存预设按钮。

调试截图使用公开场景原有配置、1280 x 720 输出。RaySteps 按实际视线采样占 Max Steps 预算的比例着色，不计二次光线步进。空密度回归测试中的平均预算占比约由 0.9926 降至 0.4570，这些是从量化热力图解码的采样占比，不是 GPU 时间或通用性能数据。大气和时间累积开关未改变测试中的诊断像素。

已完成三段真实渲染序列、更新的调试视图、跳步与调试隔离检查以及云 Shader 错误检查；尚未做 GPU 耗时、快速运动时间重建、XR 或跨平台测量。
